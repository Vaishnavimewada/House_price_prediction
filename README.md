# House Price Prediction

**Status: In Progress**

## Overview
An end-to-end Machine Learning project to predict house sale prices using the Kaggle House Prices dataset.

## Dataset
Kaggle: House Prices - Advanced Regression Techniques

The dataset contains house-related features such as overall quality, living area, garage capacity, and year built.

## Work Completed
- Loaded and explored the training and test datasets.
- Performed initial Exploratory Data Analysis (EDA).
- Analyzed missing values and duplicate records.
- Studied relationships between house features and sale prices using visualizations and correlation.
- Experimented with log transformation to reduce target skewness.

## Tech Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
